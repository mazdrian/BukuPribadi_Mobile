# 💰 Money Manager App - Setup Guide

## ⚠️ Important: Rebuilding from Scratch

This app is being rebuilt as a **Money Management Application**. The old internship tracking code has been replaced with a proper expense/income tracking system.

## 🎯 App Features

### Core Features
- **User Authentication** - Secure login/signup with Firebase Auth
- **Multiple Books** - Create separate books for different purposes (daily, projects, etc.)
- **Transaction Management** - Track income and expenses with:
  - Date
  - Category (Food, Transport, Shopping, etc.)
  - Description
  - Amount
- **Categories** - Predefined categories with custom icons and colors
- **Cloud Database** - Data synced across devices with Firestore
- **Error Handling** - Comprehensive error messages throughout

### UI Design
- Modern, clean interface inspired by popular money apps
- Material Design 3
- Beautiful purple/teal color scheme
- Smooth animations and transitions

## 🚀 Setup Instructions

### 1. Prerequisites

```bash
Flutter SDK >= 3.0.0
Dart SDK >= 3.0.0
Firebase account (free)
```

### 2. Install Dependencies

```bash
flutter pub get
```

### 3. Configure Firebase

**Option A: Using FlutterFire CLI (Recommended)**

```bash
# Install FlutterFire CLI
dart pub global activate flutterfire_cli

# Configure Firebase for your project
flutterfire configure
```

This will:
- Connect to your Firebase project
- Generate `firebase_options.dart`
- Configure Android, iOS, Web, etc.

**Option B: Manual Setup**

1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Create a new project or select existing
3. Add Android app:
   - Package name: `com.example.kerja_praktik_app`
   - Download `google-services.json`
   - Place in `android/app/`
4. Add iOS app (if needed):
   - Bundle ID: `com.example.kerjaPraktikApp`
   - Download `GoogleService-Info.plist`
   - Place in `ios/Runner/`

### 4. Enable Firebase Services

In Firebase Console:

1. **Authentication**
   - Go to Authentication → Sign-in method
   - Enable "Email/Password"

2. **Firestore Database**
   - Go to Firestore Database
   - Create database
   - Start in **test mode** (for development)
   - Choose location closest to you

3. **Firestore Rules** (Initial - for development):
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{userId} {
         allow read, write: if request.auth != null && request.auth.uid ==userId;
       }
       match /books/{bookId} {
         allow read, write: if request.auth != null && 
                              resource.data.userId == request.auth.uid;
       }
       match /transactions/{transactionId} {
         allow read, write: if request.auth != null && 
                              resource.data.userId == request.auth.uid;
       }
     }
   }
   ```

### 5. Update Firebase Initialization

Edit `lib/main.dart`'s Firebase initialization if using manual setup:

```dart
import 'firebase_options.dart'; // Generated by flutterfire configure

await Firebase.initializeApp(
  options: DefaultFirebaseOptions.currentPlatform,
);
```

### 6. Run the App

```bash
flutter run
```

OR for specific device:

```bash
flutter run -d android    # Android
flutter run -d ios        # iOS  
flutter run -d chrome     # Web
```

## 🐛 Troubleshooting

### Firebase not initialized error

Solution:
```bash
flutterfire configure
```

### Build errors on Windows

Enable Developer Mode for symlink support:
```
start ms-settings:developers
```

### Gradle build fails

```bash
cd android
./gradlew clean
cd ..
flutter clean
flutter pub get
flutter run
```

### Hot reload not working

Press `R` in terminal for hot restart
